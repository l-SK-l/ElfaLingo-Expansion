# ElfaLingo: Add to Deck — Privacy Policy

_Last updated: 17 October 2026_

ElfaLingo: Add to Deck ("the extension") adds words you select on web pages
to your deck in ElfaLingo, a language-learning app that runs on a server you
choose. This policy explains what the extension handles and where it goes.

## What the extension handles

| Data | When | Where it goes |
|---|---|---|
| The text you select and send with "Add to ElfaLingo" | Only when you click that menu item | Only to the ElfaLingo server you configured |
| Your email and password | When you sign in on the settings page | Only to the ElfaLingo server you configured |
| Session tokens issued by that server | After you sign in | Stored in your browser (see below) |
| The server address and your email | When you sign in | Stored in your browser, to prefill the form |

The extension does **not** read pages you visit, does not see text you do not
explicitly send, does not track browsing, and contains no analytics,
advertising or third-party code. It makes network requests only to the
server address you entered.

## Storage

- **Your password is never stored.** It is sent once to your server in
  exchange for session tokens.
- With **"Remember sign-in"** on, the session tokens are kept in the
  extension's local storage until you sign out. With it off, they are kept in
  memory only and are erased when the browser closes.
- Words that could not be sent yet (for example, while offline) are kept in
  the extension's local storage until they are delivered. Signing out
  deletes them.
- Uninstalling the extension deletes everything it stored.

## Sharing

The extension does not sell, transfer or share your data with anyone. The
data goes only to the ElfaLingo server whose address you entered; that
server is operated by you or by whoever runs your ElfaLingo instance, and
its own privacy terms apply to what it stores.

The use of information received by the extension adheres to the
[Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq),
including the Limited Use requirements.

# ElfaLingo: добавить в колоду — политика конфиденциальности

_Обновлено: 17 октября 2026 г._

Расширение «ElfaLingo: добавить в колоду» добавляет выделенные на страницах
слова в вашу колоду ElfaLingo — приложения для изучения языков, которое
работает на выбранном вами сервере. Здесь описано, какие данные расширение
обрабатывает и куда они попадают.

## Какие данные обрабатываются

| Данные | Когда | Куда |
|---|---|---|
| Выделенный текст, отправленный через «Добавить в ElfaLingo» | Только по нажатию этого пункта меню | Только на указанный вами сервер ElfaLingo |
| Email и пароль | При входе на странице настроек | Только на указанный вами сервер ElfaLingo |
| Токены сессии, выданные сервером | После входа | Хранятся в браузере (см. ниже) |
| Адрес сервера и email | При входе | Хранятся в браузере, чтобы заполнить форму |

Расширение **не** читает посещаемые страницы, не видит текст, который вы
явно не отправили, не отслеживает просмотр сайтов и не содержит аналитики,
рекламы и стороннего кода. Сетевые запросы идут только на указанный вами
адрес сервера.

## Хранение

- **Пароль не сохраняется.** Он один раз отправляется на ваш сервер в обмен
  на токены сессии.
- С галочкой **«Запомнить вход»** токены хранятся в локальном хранилище
  расширения, пока вы не выйдете. Без неё — только в памяти и стираются при
  закрытии браузера.
- Слова, которые пока не удалось отправить (например, без сети), хранятся в
  локальном хранилище расширения до отправки. Выход из аккаунта их удаляет.
- Удаление расширения стирает всё, что оно сохранило.

## Передача третьим лицам

Расширение не продаёт, не передаёт и не раскрывает ваши данные никому.
Данные уходят только на сервер ElfaLingo по указанному вами адресу; этим
сервером управляете вы или тот, кто держит ваш экземпляр ElfaLingo, и к
хранимому на нём применяются его правила.

Использование данных, полученных расширением, соответствует
[политике Chrome Web Store в отношении пользовательских данных](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq),
включая требования Limited Use.
